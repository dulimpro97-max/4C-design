# 4C Studio - Agence Digitale Premium

![Netlify Status](https://api.netlify.com/api/v1/badges/3b0dcc75-e58c-4aeb-a72e-ab6ba47af3b5/deploy-status)

Site vitrine pour **4C Studio**, une agence digitale premium spécialisée dans la création de sites web, l'identité de marque et le référencement.

## 🚀 Technologies

- **React 19** - Framework UI
- **Vite** - Build tool ultra-rapide
- **Framer Motion** - Animations fluides
- **Lucide React** - Icônes élégantes
- **Google Fonts** - Manrope + Playfair Display

## 🎨 Identité visuelle

- Palette : Noir (#0B0B0B) et Or (#D4AF37)
- Typographies : Manrope (corps) et Playfair Display (titres)
- Design minimaliste et premium

## 📦 Installation

```bash
# Cloner le projet
git clone https://github.com/tonpseudo/4c-studio.git

# Accéder au dossier
cd 4c-studio

# Installer les dépendances
npm install

# Lancer en développement
npm run dev

# Build pour la production
npm run build
